# Phase 1 plan

One task per session, in order where dependencies apply. Stop after Phase 1; do not implement scoring, Django APIs, or UI.

- [x] **P1-01 Sign off the inventory** — **Goal:** reconcile `data/inventory_report.md` with every supplied input and unresolved `TBD`. **Specs:** `00_overview.md` §9; `02_data_inputs.md` §§2, 4–5. **Done:** every input is inventoried, every mismatch is reported, and each unknown is resolved or an explicit owner question.
- [ ] **P1-02 Close the phosphorus gate** — **Goal:** obtain and verify the exact `sg_p` product, unit, scaling, and back-transformation. **Specs:** `01_grid_and_bands.md` §4; `02_data_inputs.md` §§2.2, 5.1. **Done:** provenance and checks are recorded in the inventory report and the owner approves inclusion; otherwise final stack assembly remains blocked.
- [x] **P1-03 Establish the project runtime** — **Goal:** create the approved Python 3.12 `.venv` and pin only Phase 1 dependencies. **Specs:** `00_overview.md` §§4, 7; `02_data_inputs.md` §4. **Done:** imports and GDAL bindings smoke-test inside the venv without changing system Python.
- [x] **P1-04 Add canonical-grid validation** — **Goal:** implement and test `assert_matches_grid` using `config.grid` exports. **Specs:** `01_grid_and_bands.md` §§1–2, 8; `02_data_inputs.md` §1. **Done:** equivalent CRS, shape, all affine terms, and pixel-is-area are checked; mismatches fail with clear diagnostics.
- [x] **P1-05 Prove the COG storage contract** — **Goal:** prototype mixed logical band types in one float32 COG. **Specs:** `01_grid_and_bands.md` §§3, 7–8. **Done:** `-9999`, 256×256 tiling, DEFLATE/predictor 3, names/tags, and average-versus-mode overviews round-trip correctly.
- [x] **P1-06 Build administrative grid bands** — **Goal:** derive `ethiopia_mask`, deterministic `woreda_id`, and a persisted P-code lookup. **Specs:** `01_grid_and_bands.md` §§4, 6; `02_data_inputs.md` §§3, 5.6. **Done:** cell-centre rasterization matches the canonical grid, IDs are stable, and mask/lookup counts reconcile to v04 boundaries.
- [x] **P1-07 Align EthioSIS estimates** — **Goal:** stage the 11 `es_*` nutrients and `es_confidence` without interpolation. **Specs:** `01_grid_and_bands.md` §§4, 8; `02_data_inputs.md` §§5.2. **Done:** only the first 1812 columns are copied, the discarded column is verified empty, nutrient-specific nulls are preserved, and an audit is written.
- [x] **P1-08 Derive mean slope in degrees** — **Goal:** convert valid 90 m percentage pixels to degrees before common-grid averaging. **Specs:** `00_overview.md` §3; `01_grid_and_bands.md` §§4, 6; `02_data_inputs.md` §5.4. **Done:** `slope_mean_deg` matches the canonical grid and provenance proves no conversion of averaged percentages.
- [x] **P1-09 Stage soil and elevation bands** — **Goal:** prepare the exact-grid SoilGrids bands except phosphorus, plus `elevation_m`. **Specs:** `01_grid_and_bands.md` §§4, 6; `02_data_inputs.md` §§5.1, 5.3. **Done:** grid checks pass, `sg_n` remains mg/kg without rescaling, outside-mask cells are nodata, and source metadata is ready for the manifest.
- [ ] **P1-10 Stage land-cover and climate bands** — **Goal:** prepare categorical land cover, nine seasonal-rainfall bands, and three canonical temperature bands. **Specs:** `01_grid_and_bands.md` §§4, 6; `02_data_inputs.md` §§5.5, 5.7–5.8. **Done:** class codes are unchanged, rainfall reuses the seasonal product, temperature names map explicitly to `_c`, and all grid/range checks pass.
- [ ] **P1-11 Stage approved phosphorus** — **Goal:** apply only the verified product-specific transform to produce `sg_p`. **Specs:** `01_grid_and_bands.md` §4; `02_data_inputs.md` §5.1. **Done:** the canonical-grid band, unit, transform, provenance, and sanity statistics agree with the P1-02 approval.
- [ ] **P1-12 Assemble stack v1 and manifest** — **Goal:** build the 38 core bands in fixed group order. **Specs:** `00_overview.md` §9; `01_grid_and_bands.md` §§3–7; `02_data_inputs.md` §3. **Done:** `common_stack_v1.tif` is a valid COG and `band_manifest.json` exactly matches descriptions, units, logical/physical types, nodata, sources, and `stack_version: 1`.
- [ ] **P1-13 Validate stack v1** — **Goal:** run the full raster acceptance suite. **Specs:** `00_overview.md` §9; `01_grid_and_bands.md` §8. **Done:** alignment, masking, ranges, EthioSIS rules, overview semantics, source round-trips, and Addis/Danakil/highland spot checks pass or are reported.
- [ ] **P1-14 Unblock named-object tooling** — **Goal:** obtain a disposable PostGIS target and compatible `psql`, PMTiles, and tippecanoe tooling. **Specs:** `00_overview.md` §9; `02_data_inputs.md` §5.9; `04_api_and_database.md` §§3–4. **Done:** versions and a test connection are recorded; no loader work starts before this passes.
- [ ] **P1-15 Create the standalone PostGIS schema** — **Goal:** add an idempotent Phase 1 schema/audit foundation under `pipeline/04_load/`. **Specs:** `04_api_and_database.md` §§3–4. **Done:** SRID 4326 tables, constraints, transactions, and required GiST/search indexes are integration-tested without creating Django code.
- [ ] **P1-16 Load woredas** — **Goal:** load full-resolution woreda polygons with parent metadata and the stack's raster IDs. **Specs:** `02_data_inputs.md` §5.6; `04_api_and_database.md` §§3–4. **Done:** source counts, geometry repairs/rejections, P-codes, centroids, and `woreda_id` lookup all reconcile on repeat runs.
- [ ] **P1-17 Load administrative capitals** — **Goal:** load the approved capital points with source-aware stable identities. **Specs:** `00_overview.md` §3; `02_data_inputs.md` §§2.5, 5.10; `04_api_and_database.md` §§3–4. **Done:** all accepted records and duplicate-key findings are audited without treating capitals as all towns or markets.
- [ ] **P1-18 Load EthioSIS samples** — **Goal:** clean and load sample points without altering the CSV. **Specs:** `02_data_inputs.md` §5.2; `04_api_and_database.md` §§3–4. **Done:** header mappings, invalid coordinates, nonpositive/outlier nulling, coordinate deduplication, batch counts, and GiST index reconcile on repeat runs.
- [ ] **P1-19 Load normalized roads** — **Goal:** load only approved motor-road lines and derived capital context for unnamed roads. **Specs:** `00_overview.md` §3; `02_data_inputs.md` §5.9; `04_api_and_database.md` §§3–5. **Done:** every source geometry is accounted for, IDs/parts and original names are preserved, classes are mapped from `highway`, and derived context is explicitly labelled.
- [ ] **P1-20 Validate PostGIS datasets** — **Goal:** prove loader idempotency, reconciliation, and indexed spatial queries. **Specs:** `00_overview.md` §9; `04_api_and_database.md` §§4–5. **Done:** rerun counts are stable, repairs/rejections are logged, `VACUUM ANALYZE` runs, and `EXPLAIN` plus true geography-distance checks pass.
- [ ] **P1-21 Build roads PMTiles** — **Goal:** package normalized roads into main-road and all-road display layers. **Specs:** `00_overview.md` §9; `02_data_inputs.md` §5.9; `04_api_and_database.md` §9. **Done:** `roads.pmtiles` has the approved classes, expected zoom visibility, stable attributes, and OSM attribution.
- [ ] **P1-22 Smoke-test the display asset** — **Goal:** serve `roads.pmtiles` with HTTP Range support in a minimal test page. **Specs:** `00_overview.md` §§4, 9; `04_api_and_database.md` §§9, 13. **Done:** both road layers load at representative zooms and range requests are verified; this does not start the Phase 3 app.
- [ ] **P1-23 Close Phase 1** — **Goal:** run and record the complete Phase 1 acceptance check. **Specs:** `00_overview.md` §9; `01_grid_and_bands.md` §8; `04_api_and_database.md` §4. **Done:** raster, manifest, PostGIS, and PMTiles deliverables are reproducible and reconciled, approved policies are recorded, access bands remain deferred, and no Phase 2/3 work is included.
